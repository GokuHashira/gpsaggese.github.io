Demo of small language models (119M–1.31B parameters) trained from scratch for math
word problems and logical reasoning (MSML610, University of Maryland, Fall 2026).
Set the `SLM_MODELS` variable ("Name=user/repo;Name2=user/repo2") to choose the models.
